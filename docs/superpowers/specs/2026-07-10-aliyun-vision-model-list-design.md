# 阿里云百炼视觉模型列表更新设计

## 目标

更新“添加通义千问（阿里云百炼）视觉模型”中的基础模型候选项，避免用户选择已经下线或即将下线的旧版 Qwen-VL 模型。

## 变更范围

- 将视觉模型候选列表更新为：
  - `qwen3-vl-plus`
  - `qwen3-vl-flash`
- 移除以下候选项：
  - `qwen-vl-max`
  - `qwen-vl-max-0809`
  - `qwen-vl-plus-0809`
- 保留现有自定义输入能力，允许用户手动录入其他兼容模型名称。
- 不修改数据库结构，不迁移或删除已经保存的旧模型配置。

## 实现方式

仅修改阿里云百炼模型供应商的视觉模型注册列表。复用现有 `QwenVLChatModel` 和 `QwenVLModelCredential`，不引入新适配器或依赖。`qwen3-vl-plus` 作为默认视觉模型，`qwen3-vl-flash` 作为速度与成本优先的备选。

## 兼容性

已保存的旧模型记录仍可读取和编辑；本次修改只影响新建模型时的下拉候选项。由于供应商对自定义模型名称会回退到默认视觉模型适配器，手动输入能力保持不变。

## 验证

- 新增或更新单元测试，断言阿里云百炼的 IMAGE 模型列表只包含两个新型号。
- 先运行测试并确认旧实现失败，再修改注册列表使测试通过。
- 运行仓库规则校验脚本 `./scripts/validate-code-rules.sh`。

## 非目标

- 不修改文档图文分段的批次大小、重试或错误展示逻辑。
- 不自动修改现有数据库中的模型名称。
- 不调整阿里云 API 地址或用户凭证。
